About Categories

Categories organize your KB documents and influence retrieval. When a Member asks a question, VEC_DISTANCE_COSINE() finds the nearest chunks and the category Priority Boost adds a score bonus to surface the most relevant category first.

Tags provide finer-grained filtering. A document can have multiple tags across categories for cross-topic discoverability.

Tuning Guide

M parameter: Start with 6 for <50K vectors. Increase to 12–16 for 200K+ vectors. Higher M increases insert time but improves search accuracy.

ef_search: Controls recall during queries. Default 20 is fine for most Q&A workloads. Increase to 100+ if you notice relevant chunks being missed.

Cache size: Rule of thumb: 1.5× your total vector data. For 8K chunks × 1536 dimensions × 4 bytes = ~47 MB raw, so 128–512 MB cache is ample.

Distance metric: Always use cosine for text embeddings from OpenAI, Cohere, or similar. euclidean is for normalized image vectors.

CLI equivalent
SET GLOBAL mhnsw_default_m = 6;

-- MariaDB 11.7+ native vector search
SET @q = VEC_FromText('[0.91,0.84,0.14,...]');

SELECT
  ce.chunk_id,
  d.title,
  ce.section_title,
  ROUND(1 - VEC_DISTANCE_COSINE(
    ce.embedding, @q
  ), 4) AS similarity
FROM kb_chunk_embeddings ce
JOIN kb_documents d ON d.document_id = ce.document_id
JOIN kb_categories cat ON cat.category_id = d.category_id
WHERE ce.is_active = 1 AND d.status = 'active'
ORDER BY VEC_DISTANCE_COSINE(ce.embedding, @q) ASC
LIMIT 5;

-- VECTOR INDEX (HNSW, DISTANCE=cosine) auto-used
