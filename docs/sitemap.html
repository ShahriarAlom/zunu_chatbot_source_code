Zunu AI Chatbot Sitemap & Architecture

A comprehensive sitemap, components breakdown, and visual data flow of the chatbot system.

System Sitemap & Data Flow

1. User / Guest

Loads page. If not logged in, interacts as Guest. If logged in, member session token is verified.

➜

2. JS Chat Widget

Handles UI layout. Connects via WebSocket. Initiates guest merge if user logs in mid-session.

➜

3. FastAPI Backend

Coordinates WebSocket connections, routes user queries to LLM agent, checks timeout events.

➜

4. LangChain Agent

Decides to query inventories, databases, or RAG vectors based on semantic query analysis.

1 Frontend Widget (JS)

  • rdr_chatbot.js: Self-injected script, handles responsive chat window styles and markdown rendering.
  • WebSocket Manager: Maintains persistent chat sockets.
  • Local Storage Cache: Stores guest session IDs to retrieve past history across refreshes.

2 FastAPI Backend (Python)

  • app.py: Serves WebSocket endpoints (`/ws/chat` and `/ws/admin`) and session API.
  • socket_manager.py: Manages state machine (AI bot, pending takeover, human active, ticket fallback).
  • ai_engine.py: LangChain intelligent agent utilizing specialized database tools.

3 MariaDB Vector DB

  • kb_documents: Tracks corporate policies, versions, and chunk states.
  • kb_chunk_embeddings: Stores text snippets with native 768-dim vector embeddings and HNSW indexes.
  • query_log: Stores user questions, agent replies, and metrics for analytics.

4 Website DB (Laravel)

  • users: Selects user profiles for guest authentication and updates.
  • cars: Queries inventory to display car listings in rich grid layouts.
  • support_tickets: Receives pending support escalations and fallback details.
