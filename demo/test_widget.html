Chatbot Test Environment

This is a blank page designed solely to test the visual layout and WebSocket connection of the RealDealRide Chatbot.

How to test:

  1. Ensure your backend Docker container is running on localhost:8000.
  2. Click the floating chat bubble in the bottom right corner.
  3. Type a message like "I need an SUV in Germantown".
  4. Watch the fluid grid layout expand and collapse!
